Feature: Get User Details via Reqres API

User Story 1: Retrieve user information by ID

As a client of the Reqres API,  
I want to retrieve user details by providing a valid user ID,  
So that I can display the user's profile data in my application.

API Endpoint: https://reqres.in/api/users/{id}  
Method: GET

Functional Requirements:
- When a valid user ID is provided, the API returns status code 200 OK and the user's details in JSON format.
- If the user ID does not exist, the API returns a 404 Not Found response.
- The response body for success contains the following fields:
  - id
  - email
  - first_name
  - last_name
  - avatar
- Invalid IDs (e.g., 0, negative numbers, very large numbers) should return proper error responses.
- The API should handle invalid input formats (e.g., non-numeric values like "abc") gracefully.
- Response time should be under 2 seconds.
- Authentication is not required.

Test Data Examples:
- Valid ID: 2
- Invalid ID: 999
- Edge Cases: 0, -1, 1000000000, "abc"

You are an API automation engineer working in a Node.js + Playwright test setup.

Project Details:
- Framework: Playwright for test runner + Axios/fetch for API calls
- API Test Directory: api-tests/
- Manual Test Case Source: All manual API test cases are written in markdown inside:
  manual testcases/API-manual testcases/{FeatureName}.md


Your Responsibilities:

1. For each {FeatureName}.md inside `manual testcases/API-manual testcases/`, do the following:

   Parse and extract each manual API test case
   No testcase should get skip
   Extract the following from each test case:
     - Test Title
     - Endpoint (e.g., GET https://reqres.in/api/users/2)
     - HTTP method (GET, POST, PUT, DELETE)
     - Path/query/body parameters
     - Expected status code
     - Expected response body
     - Edge cases (e.g., 404s, empty inputs, invalid tokens)

2. For each feature, create a test file:
   File: `api-tests/api/{FeatureName}.spec.js`

   - Use:
     ```js
     const { test, expect } = require('@playwright/test');
     const apiClient = require('../../utils/apiClient');
     const testData = require('../../testData/{FeatureName}Data.json');
     ```

   - Structure:
     ```js
     test.describe('{FeatureName}', () => {
       test('TC-001: Valid request', async () => {
         const response = await apiClient.get('/users/2');
         expect(response.status).toBe(200);
         expect(response.data).toMatchObject({
           data: expect.any(Object),
           support: expect.any(Object)
         });
       });

       test('TC-002: Invalid user ID', async () => {
         const response = await apiClient.get('/users/9999');
         expect(response.status).toBe(404);
       });

       // Additional test cases from markdown...
     });
     ```

3. Create API Client:
   File: `utils/apiClient.js`
   - Use Axios or Fetch
   - Configure:
     - Base URL
     - Default headers
     - Error and response logging
   - Example:
     ```js
     const axios = require('axios');

     const api = axios.create({
       baseURL: 'https://reqres.in/api',
       headers: {
         'Content-Type': 'application/json'
       }
     });

     api.interceptors.response.use(
       (response) => {
         console.log('Response:', response.status, response.data);
         return response;
       },
       (error) => {
         console.error('Error:', error.response?.status, error.message);
         throw error;
       }
     );

     module.exports = {
       get: (url, config) => api.get(url, config),
       post: (url, data, config) => api.post(url, data, config),
       put: (url, data, config) => api.put(url, data, config),
       delete: (url, config) => api.delete(url, config)
     };
     ```

4. Create Test Data JSON:
   File: `api-tests/testData/{FeatureName}Data.json`
   - Example content:
     ```json
     {
       "validUserId": 2,
       "invalidUserId": 9999,
       "newUser": {
         "name": "John Doe",
         "job": "Engineer"
       },
       "authToken": "Bearer <REDACTED>"
     }
     ```

   - Load and use inside `.spec.js` test files:
     ```js
     const data = require('../../testData/{FeatureName}Data.json');
     ```
